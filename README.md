# UNIWA Exercises

A collection of university exercises from the **University of West Attica (UNIWA)**.

## Contents

| Folder | Subject | Description |
|---|---|---|
| [`linux-shell-scripting-exercises/`](linux-shell-scripting-exercises/) | Operating Systems / Linux | Bash scripts covering directory scanning, file backups (immediate, scheduled with `at`, and weekly via `cron`), and process inspection via `/proc` |
| [`os-process-fork-tree/`](os-process-fork-tree/) | Operating Systems | C programs demonstrating Unix process creation with `fork()`, pipes, `wait()`, and `exec()` |

Each subfolder contains its own `README.md` with build and run instructions.
