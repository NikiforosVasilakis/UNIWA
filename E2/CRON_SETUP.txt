ΟΔΗΓΙΕΣ ΓΙΑ ΤΟ CRON ΤΟΥ bck2
================================

Για να προγραμματισετε το bck2 να τρεχει καθε Κυριακη βραδυ στις 11μμ 
για τους επομενους 6 μηνες, εκτελεστε:

crontab -e

Και προσθεστε την ακολουθη γραμμη:

0 23 * * 0 /full/path/to/bck2 >> /tmp/bck2.log 2>&1

Η αν θελετε να δειτε τα αποτελεσματα στην κονσολα:

0 23 * * 0 /full/path/to/bck2

Σημειωση: 
- 0 = λεπτα (0)
- 23 = ωρες (11μμ)
- * = οποιοσδηποτε μηνας
- * = οποιαδηποτε ημερα του μηνα
- 0 = Κυριακη (0=Κυριακη, 1=Δευτερα, ..., 6=Σαββατο)

Για να δειτε τα προγραμματισμενα jobs:
crontab -l

Για να διαγραψετε το cron job μετα απο 6 μηνες:
crontab -e
(και αφαιρεστε την γραμμη)

Παραδειγμα πληρους διαδρομης:
0 23 * * 0 /home/username/scripts/bck2 >> /tmp/bck2.log 2>&1
